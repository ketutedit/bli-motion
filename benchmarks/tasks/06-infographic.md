# Benchmark 06 — Infographic and Data Motion

## Exact prompt

Create a 10-second, 1920×1080, 30 fps animated infographic showing fictional weekly signups for a sample app: Week 1 = 120, Week 2 = 180, Week 3 = 150, Week 4 = 240. Clearly label the figures as sample data. Choose a chart form that makes the comparison immediately understandable, preserve the exact values and scale, and use animation to reveal the main insight: Week 4 is highest, while Week 3 falls from Week 2. Make the result visually polished without making the data harder to read.

Deliver a runnable Remotion project and an MP4 render. Use only dependencies in the shared blank benchmark project. Do not use external images, paid assets, or network-loaded fonts.

## Evaluation focus

- Exact data, labels, and sample-data disclosure.
- Appropriate chart form, scale, and comparison.
- Visual hierarchy and legibility.
- Animation that clarifies rather than distorts the insight.
- Correct 10-second duration and stable render.

## Controlled conditions

Run the exact prompt for A, B, and C with the same model, settings, blank project, dependencies, and available tools. Do not give only one condition extra assets or implementation help.
