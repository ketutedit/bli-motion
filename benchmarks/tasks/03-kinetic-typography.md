# Benchmark 03 — Kinetic Typography

## Exact prompt

Create a 7-second, 1920×1080, 30 fps kinetic typography piece using the exact phrase: "MAKE IDEAS MOVE." Treat the words as the central visual material. Build a strong typographic composition with intentional hierarchy, rhythm, and a memorable visual transition. The treatment should feel editorial and premium, not like a default word-by-word subtitle animation. Preserve exact spelling and punctuation, and hold the final phrase clearly long enough to read.

Deliver a runnable Remotion project and an MP4 render. Use only dependencies in the shared blank benchmark project. Do not use external images, paid assets, or network-loaded fonts.

## Evaluation focus

- Originality of typographic concept.
- Readability and hierarchy throughout the animation.
- Relationship between word meaning and movement.
- Timing, rhythm, transition, and final hold.
- Correct 7-second duration and stable render.

## Controlled conditions

Run the exact prompt for A, B, and C with the same model, settings, blank project, dependencies, and available tools. Do not give only one condition extra assets or implementation help.
