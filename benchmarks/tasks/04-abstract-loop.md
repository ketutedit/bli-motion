# Benchmark 04 — Abstract Seamless Loop

## Exact prompt

Create a 6-second, 1080×1080, 30 fps abstract motion loop. Use a coherent visual system of forms, materials, color, and movement to create a sophisticated, visually engaging result. The piece should feel intentional and authored, not like random particles or a stock screensaver. Design the ending so it returns seamlessly to the opening state. Do not use text, logos, or external assets.

Deliver a runnable Remotion project and an MP4 render. Use only dependencies in the shared blank benchmark project. Do not use external images, paid assets, or network-loaded fonts.

## Evaluation focus

- Coherent visual grammar and originality.
- Quality of form, composition, material, and depth.
- Rhythm and purposeful movement.
- Actual loop continuity during playback.
- Correct 6-second duration and stable render.

## Controlled conditions

Run the exact prompt for A, B, and C with the same model, settings, blank project, dependencies, and available tools. Do not give only one condition extra assets or implementation help. Inspect the loop boundary in playback; a still frame cannot establish seamlessness.
