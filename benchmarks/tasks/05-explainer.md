# Benchmark 05 — Educational Explainer

## Exact prompt

Create a 15-second, 1920×1080, 30 fps motion-graphics explainer that teaches a beginner how DNS helps a browser find a website. Explain this sequence accurately: a user enters a domain name; a DNS resolver obtains the corresponding IP address; the browser can then connect to the destination server. Use the analogy of a contacts directory only if it makes the mechanism clearer, and do not imply that DNS is the website itself. Make the transformation from domain name to IP address visible. Keep on-screen text concise and readable.

Deliver a runnable Remotion project and an MP4 render. Use only dependencies in the shared blank benchmark project. Do not use external images, paid assets, or network-loaded fonts. Do not invent technical facts beyond the brief.

## Evaluation focus

- Factual accuracy and clarity for beginners.
- Strength of visual explanation and metaphor.
- Scene variety and continuity.
- Typography, pacing, and visual hierarchy.
- Correct 15-second duration and stable render.

## Controlled conditions

Run the exact prompt for A, B, and C with the same model, settings, blank project, dependencies, and available tools. Do not give only one condition extra assets or implementation help.
