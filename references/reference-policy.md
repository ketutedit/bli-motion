# Reference Sources and Adaptation Policy

BLI Motion studies public repositories to learn production patterns. It does not treat them as a source to copy wholesale.

## Reference: Bang Motion
Repository: https://github.com/bangtutorial/bang-motion

Useful ideas studied:
- agent skill as a router with specialist references,
- creative brief before implementation,
- explicit anti-slide / anti-PPT checks,
- separate explainer visual modes,
- starter projects for repeatable technical patterns,
- frame-snapshot verification before delivery,
- deterministic timeline behavior for seekable animation.

The repository declares an MIT license. When directly reusing or adapting its code or assets, preserve the required copyright and license notices. BLI Motion should prefer original guidance and original implementations, not wholesale copying of its skill text or starter files.

## Reference: Remotion
Repository: https://github.com/remotion-dev/remotion

Useful ideas studied:
- agent skills organized by task and routed from a central skill,
- React component and composition structure,
- explicit frame rate and frame-based timeline,
- reusable scene sequences and transitions,
- preview in Studio and rendering as a separate production step.

Remotion has a special license. Review its current terms before integrating its code or using it in a commercial application. Using a framework to render a user's video is not the same as selling a derivative of the framework.

## BLI Motion's own identity
BLI Motion's distinctive focus is educational visual storytelling:
- creative direction selected for the subject,
- factual accuracy and source traceability,
- visual explanations rather than decorative slides,
- age- and audience-appropriate communication,
- engine-independent storyboards,
- renderer adapters for HTML/GSAP, SVG/Canvas, or Remotion.

References may inform methods. They do not determine BLI Motion's output style, visual identity, scene order, or signature designs.
