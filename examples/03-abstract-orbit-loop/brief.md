# Abstract Orbit Loop Brief

- **Intent:** Create a polished, non-literal abstract motion loop.
- **Duration:** 6 seconds (180 frames at 30 fps).
- **Frame:** 1080×1080.
- **Visual grammar:** A restrained family of orbiting organic/geometric forms, rings, and repeated particles.
- **Movement:** Periodic, frame-derived transforms that return to the opening state.
- **No text, logos, external assets, or unseeded randomness.**
- **Delivery:** Remotion composition and MP4.

## Key creative point

The piece should feel like one coherent visual system rather than a random screensaver. The loop should be verified in playback, not judged from a still.
