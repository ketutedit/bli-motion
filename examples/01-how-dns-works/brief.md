# Benchmark Example: How DNS Works

## Project
- **Topic:** DNS lookup for a beginner audience
- **Audience:** General viewers with basic familiarity with web browsing
- **Duration:** 15 seconds (450 frames at 30 fps)
- **Format:** 1920×1080, 16:9
- **Tone:** Clear, editorial, friendly, and concise
- **Delivery:** Remotion composition and MP4 render

## Core message

A domain name is human-readable. A DNS resolver helps obtain the IP address associated with that domain so the browser can connect to the destination server.

## Visual idea

Use a browser address field and an editorial contact-directory analogy. Show the domain name as the lookup key, reveal a corresponding IP address, then show the destination server becoming available.

The example address `203.0.113.42` is reserved for documentation and is used as a demonstration value, not a real website destination.

## Accuracy notes

- Do not say that a DNS resolver is the website or the destination server.
- DNS can use cached records; this simplified visual focuses on the lookup relationship rather than every step of recursive resolution.
- The visual uses a contact-directory analogy. It is not a literal depiction of all DNS infrastructure.

## Constraints

- No external images or remote fonts.
- No invented public IP address or real service branding.
- Use motion to clarify the lookup and result.
- Keep labels readable at 1920×1080.
