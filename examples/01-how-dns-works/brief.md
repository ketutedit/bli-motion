# Test Case Brief: How DNS Works

## 1. Project Overview
- **Topic**: Cara Kerja DNS (Domain Name System)
- **Target Audience**: Pemula / Penonton Umum yang ingin paham internet
- **Duration**: 15 detik (450 frames @ 30fps)
- **Aspect Ratio**: 16:9 (1920x1080)
- **Tone**: Ringan, edukatif, bersahabat, analogis

## 2. Subject Breakdown
- **Core Insight**: Komputer tidak paham nama domain (seperti `google.com`), komputer hanya paham angka IP Address. DNS adalah "buku kontak telepon" internet.
- **Key Metaphor**: Mencari nomor telepon teman di buku kontak handphone.
- **Cause & Effect**: User mengetik domain -> DNS menerjemahkan ke IP -> Browser membuka website.

## 3. Communication Constraints
- Dilarang membuat tampilan slide presentasi dengan bullet points.
- Harus ada karakter ilustrasi yang mengalami masalah/pertanyaan.
- Transisi antar scene harus membawa perhatian penonton (continuity flow).
