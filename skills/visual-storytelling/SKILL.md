# Visual Storytelling Skill

## Purpose
Turn information into a visual sequence that creates understanding.

## Story logic
Find the strongest structure for the subject:
- question → answer,
- problem → cause → solution,
- whole → parts → relationship,
- before → change → after,
- step 1 → step 2 → result,
- misconception → correction,
- comparison → conclusion.

Do not force every topic into the same story structure.

## Visual thinking
Translate abstract ideas into visual relationships:
- scale for magnitude,
- distance for separation,
- connecting lines for relationships,
- containers for categories,
- paths for journeys or processes,
- layers for systems,
- transformation for change,
- repeated objects for quantity or pattern.

Use metaphor only when the mapping is clear and culturally appropriate.

## Scene progression
Each scene should:
- answer a question,
- introduce a new piece of information,
- clarify a relationship,
- or create a meaningful emotional beat.

The end of a scene should prepare the next scene. Reuse or transform visual elements to create continuity.

## Hook and payoff
Start with a relevant question, surprising contrast, recognizable situation, or visual puzzle. Avoid clickbait that promises more than the content delivers. End by resolving the opening idea or reinforcing the key takeaway.

## Narration and image
Do not merely illustrate every spoken word literally. Let voiceover explain while visuals demonstrate relationships, examples, scale, or change. Use on-screen text for key terms and short takeaways, not a duplicate transcript.
