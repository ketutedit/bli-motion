# Infographic Design Skill

## Purpose
Make data, processes, categories, and relationships understandable at a glance.

## Choose the right visual
- comparison → side-by-side bars, paired objects, or aligned metrics,
- proportion → bar, stacked bar, or carefully justified part-to-whole chart,
- trend → line or sequential states,
- process → numbered steps or connected path,
- hierarchy → tree or nested structure,
- system → labeled diagram,
- geography → map only when location matters,
- quantity → repeated units or a chart with a clear scale.

Do not use a chart type just because it looks attractive.

## Data integrity
- Preserve units, scale, labels, and source context.
- Never invent or distort values.
- Make zero baselines and axis choices appropriate to the chart.
- Distinguish observed data from estimates or illustrative examples.
- If data is unavailable, use a conceptual diagram rather than fake numbers.

## Visual hierarchy
Highlight the insight, not every data point. Use labels close to the relevant marks. Keep legends simple and avoid forcing viewers to decode unnecessary colors.

## Animation
Reveal data in a logical order:
1. establish what is being measured,
2. show the scale or categories,
3. animate values or relationships,
4. emphasize the main insight,
5. leave the complete chart visible long enough to understand.

## Accessibility
Never rely on color alone to encode meaning. Use labels, patterns, shape, or position as additional cues.
